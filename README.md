# Hey-Jarvis-Wake-Up
Hey guys! I built this script to launch Jarvis using 2 claps + voice or text. I hated Windows UAC popups freezing the launch, so this auto-bypasses Admin prompts! Setup: Use Python 3.11 (3.14 breaks pyaudio). pip install pyaudio SpeechRecognition pyttsx3  Just update app_path, run VS Code as Admin, and you're set. Happy coding! ✌️
Work only python 3.11 version
